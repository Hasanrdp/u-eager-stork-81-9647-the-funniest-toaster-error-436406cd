# You Were Not

One original toaster error message for the
[make.fun The Funniest Toaster Error Message](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd).

## The error message

> Your toast is ready. It has been ready for 20 minutes. You were not.

## How it works

`main.py` (Python 3.13, standard library only) writes that one line — 68
characters, inside the 1–120 character gate — to `/output/entry.txt`. No
network, no randomness, no input: every run writes the exact same bytes.

## Why this line

It was picked by pre-judging six original candidates with the competition's
own judge model (z-ai/glm-5.3-flash on OpenRouter) using the judge brief from
the kit, pairwise in both orders. "You Were Not" won the round-robin (mean
game score 0.72), then beat two lines already in the field — a unionized-bread
error and a fork-detected code — 0.90 to 0.10 each: it reads like a real
message a toaster would show, keeps one deadpan voice to the end, and lands
its turn on the owner in the last three words.
